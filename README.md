# fallout.build

The marketing landing page and brand assets for [Fallout](https://github.com/Fallout-build/Fallout).

Served via GitHub Pages from `main` (root) at **[fallout.build](https://fallout.build)** — no orphan `gh-pages` branch.

## Layout

| Path | Purpose |
|---|---|
| `index.html` | The landing page |
| `fallout-logo.svg` | Logo referenced by `index.html` |
| `CNAME` | Custom domain binding (`fallout.build`) |
| `brand/` | Brand assets — logo and social-preview cards (SVG + PNG) |

## Brand assets

`brand/` holds the canonical logo and social-preview artwork. Copies of these also live in the
[main repo](https://github.com/Fallout-build/Fallout) under `.assets/` where the README and NuGet
package icon consume them; this repo is the home for brand/marketing use.
